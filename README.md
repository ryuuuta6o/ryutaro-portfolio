# Ryutaro Tachibana portfolio

橘 龍太郎の日本語・英語ポートフォリオ。現場の課題整理、生成AIを活用した実装、動作確認・改善を、実際の制作画面とともに紹介します。

- 公開: https://ryutaro-portfolio-orpin.vercel.app/
- 日本語: `/`
- English: `/en/`
- 作品データ・文章: `src/data/portfolio.ts`
- 表示: `src/components/sites/ryutaro/PortfolioSite.tsx`
- 文字・レイアウト: `src/app/globals.css`
- 写真と作品画像: `public/sites/ryutaro/`

Node.js 24で `npm ci`、`npm run dev`。公開前に `npm run check` を実行します。

Next.jsの構成には [ai-website-cloner-template](https://github.com/JCodesMore/ai-website-cloner-template) を使用しました。ライセンスは `LICENSE` を参照してください。
